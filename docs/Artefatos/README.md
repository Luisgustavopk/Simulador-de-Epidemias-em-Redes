## Etapa 1 — Problema, modelagem e planejamento

**[Abrir o PDF único da Etapa 1](Etapa1-Problema-Modelagem-Plano.pdf)**.

As referências e os anexos integram o mesmo PDF. O [Markdown](Etapa1-Problema-Modelagem-Plano.md) é a fonte editável.
